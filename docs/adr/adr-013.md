# ADR 0013: KI-Integration via deterministischer Prompt-Zellen

**Status:** Akzeptiert
**Kontext:**
Die Einbindung von Sprachmodellen (LLMs) und lokalen Klassifikatoren (z. B. das Jev-Modell zur Relevanzprüfung) fördert den kreativen und analytischen Schreibprozess enorm. Herkömmliche Editoren lösen dies meist über schwebende, transiente Chat-Fenster (Copilot-Ansatz). Das bricht jedoch mit Rosidas Kernprinzipien: flüchtige Chats sind nicht versionierbar, nicht im Text verankert und stören den SDI-Flow. Es wird ein Weg benötigt, KI-Interaktionen als reproduzierbaren Bestandteil des Plain-Text-Dokuments zu behandeln.

**Entscheidung:**
KI-Interaktionen werden als eigenständiger, ausführbarer Code-Block-Typ in das Markdown-Dokument integriert.

1. **Syntax:** Es wird ein neuer Zell-Typ ````prompt` eingeführt.
2. **Konfiguration:** Metadaten wie das Ziel-Modell oder der Kontext werden als Parameter im Block definiert (entweder als Quarto-ähnliche Kommentare `#| model: jev-classifier` oder YAML).
3. **Ausführung:** Ein neuer `PromptExecutor` (parallel zum `PythonExecutor`) verarbeitet den Block bei `Ctrl+Enter`. Er liest den Prompt, sendet ihn an das konfigurierte Backend (lokal via API/Ollama oder extern) und wartet auf die Antwort.
4. **Output:** Die Rückgabe der KI wird als statischer, bearbeitbarer Markdown-Text exakt unterhalb der Zelle in das Dokument injiziert (eingefrorener Zustand).
5. **Quarto-Export:** Um Prompt-Blöcke im finalen PDF-Export zu verbergen, können Quarto-Optionen wie `#| echo: false` und `#| eval: false` genutzt werden.

**Konsequenzen:**

* **Positiv:** Prompts und Modellantworten werden persistent und reproduzierbar. Sie landen als reiner Text im Git-Repository.
* **Positiv:** Zero UI-Bloat. Es wird kein separates Chat-Dock benötigt, der Text-Editor bleibt das universelle Interface.
* **Positiv:** Hohe Modularität. Du kannst nahtlos zwischen einem lokalen Klassifikator (Jev) zur Qualitätskontrolle, lokaler Code-KI oder externen APIs wechseln, nur durch Änderung eines Parameters.
* **Negativ/Trade-off:** Netzwerk-Calls oder lokale GPU-Inferenz haben Latenz. Der `PromptExecutor` muss zwingend asynchron (via `QThread` in Qt) laufen, damit die UI während der Generierung nicht einfriert.
