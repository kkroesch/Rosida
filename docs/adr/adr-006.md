# ADR 0006: Nicht-modales Fehler-Handling via Inline-Akkordeon und System-Log-Drawer

* **Status:** Akzeptiert
* **Datum:** 2026-09-25
* **Kontext:** Rosida (UI/UX, Fehlerbehandlung, Kernel-Monitoring, SDI-Architektur)

---

## 1. Kontext und Problemstellung

In GUI-Anwendungen führt klassisches Exception-Handling häufig zu zwei Extremen:

1. **Modale Fehler-Dialoge:** Popups unterbrechen den Tastaturfokus, blockieren den Arbeitsfluss und erzeugen bei kaskadierenden Folgefehlern frustrierende Klick-Orgien.
2. **Lautloses Verpuffen:** Wird eine Anwendung ohne Terminal gestartet (z. B. via Desktop-Icon, AppImage, Flatpak), landen unhandled Exceptions auf `stderr` im Nirwana. Die Anwendung wirkt blockiert oder reagiert ohne sichtbare Rückmeldung.

Zudem muss strikt zwischen zwei Fehlerklassen unterschieden werden:

* **Code-Fehler des Nutzers (User Space):** Syntaxfehler, ungültige Indizes oder Berechnungsfehler im Notebook-Code. Diese sind Teil des normalen interaktiven Entwicklungsworkflows und keine Anwendungsfehler von Rosida.
* **System- und Kernel-Fehler (App Space):** Absturz des Worker-Subprozesses (Segfaults, Exit $\neq 0$), IPC-Protokollfehler, I/O-Probleme beim Speichern oder unhandled Qt-Exceptions im GUI-Thread.

---

## 2. Architekturentscheidung

Wir verbieten modale Hinweisboxen für Exceptions und etablieren eine zweistufige, kontextbezogene Fehlerdarstellung:

### 2.1 Zell-Fehler: Inline-Akkordeon

Fehler, die während der Zellausführung im Python-Worker entstehen, werden direkt unterhalb der Quellzelle dargestellt:

* **Default-Zustand (Eingeklappt):** Zeigt lediglich die letzte signifikante Fehlerzeile (z. B. `ZeroDivisionError: division by zero`) in roter Typografie mit vorgestelltem Chevron-Indikator.
* **Interaktion (Klick / Aufgeklappt):** Expandiert einen Monospace-Block mit dem vollständigen Stacktrace.

```text
┌────────────────────────────────────────────────────────┐
│ ▼ ZeroDivisionError: division by zero                  │
│   File "<cell>", line 2, in <module>                   │
│     res = 10 / 0                                       │
│   ZeroDivisionError: division by zero                  │
└────────────────────────────────────────────────────────┘

```

Die Statusbar bleibt bei Zell-Fehlern unberührt, um ein Abstumpfen des Indikators zu verhindern.

### 2.2 System- und Kernel-Fehler: Statusbar-Stoppschild & Bottom-Drawer

Laufzeitfehler von Rosida und Abstürze des Kernel-Prozesses werden zentral abgefangen und in der Statusleiste signalisiert:

* **Statusbar-Indikator:** Ein rotes Oktagon-Stoppschild mit einer einzeiligen Kurzmeldung erscheint am linken Rand der Statusleiste.
* **Bottom-Drawer:** Ein Klick auf das Stoppschild klappt am unteren Fensterrand ein Log-Panel auf (realisiert über einen vertikalen `QSplitter`).

```text
┌───────────────────────────────────────────────────────────┐
│                    Document Canvas                        │
│                                                           │
├───────────────────────────────────────────────────────────┤
│ ▼ System-Log                         [ In Zwischenablage ] │
│ [14:22:01] CRITICAL Kernel crashed with exit code 139     │
│ Stacktrace:                                               │
│   File "rosida/kernel.py", line 84, in on_process_error   │
│     raise KernelCrashError(...)                           │
└───────────────────────────────────────────────────────────┘
│ 🛑 Kernel abgestürzt (Exit 139)            Ln 12, Col 4   │
└───────────────────────────────────────────────────────────┘

```

## 3. Technische Implementierung

### 3.1 Globale Error-Bridge & Hook

```python
import sys
import traceback
from PySide6.QtCore import QObject, Signal


class GlobalErrorBridge(QObject):
    error_occurred = Signal(str, str)  # (Kurzmeldung, Vollständiger Traceback)


error_bridge = GlobalErrorBridge()


def install_global_excepthook():
    def _hook(exctype, value, tb):
        full_tb = "".join(traceback.format_exception(exctype, value, tb))
        short_msg = f"{exctype.__name__}: {value}"
        # Fehler an UI weiterleiten
        error_bridge.error_occurred.emit(short_msg, full_tb)
        # Für CLI / Entwicklungsbetrieb weiterhin auf stderr ausgeben
        sys.__excepthook__(exctype, value, tb)

    sys.excepthook = _hook

```

### 3.2 Statusbar-Komponente (`ErrorStatusWidget`)

```python
from PySide6.QtCore import Qt
from PySide6.QtWidgets import QHBoxLayout, QLabel, QWidget
import qtawesome as qta


class ErrorStatusWidget(QWidget):

    def __init__(self, on_click_callback, parent=None):
        super().__init__(parent)
        self.on_click = on_click_callback
        self.setCursor(Qt.PointingHandCursor)

        layout = QHBoxLayout(self)
        layout.setContentsMargins(4, 0, 8, 0)
        layout.setSpacing(6)

        # Rotes Stopp-Icon (Oktagon)
        self.icon_label = QLabel()
        self.icon_label.setPixmap(
            qta.icon("fa5s.stop-circle", color="#e06c75").pixmap(14, 14)
        )

        self.text_label = QLabel()
        self.text_label.setStyleSheet("color: #e06c75; font-weight: bold;")

        layout.addWidget(self.icon_label)
        layout.addWidget(self.text_label)
        self.hide()

    def show_error(self, message: str):
        short = message if len(message) < 60 else message[:57] + "..."
        self.text_label.setText(short)
        self.show()

    def mousePressEvent(self, event):
        if event.button() == Qt.LeftButton:
            self.on_click()

```

### 3.3 Log-Drawer & MainWindow-Integration

```python
from PySide6.QtCore import Qt
from PySide6.QtWidgets import (
    QApplication,
    QHBoxLayout,
    QLabel,
    QMainWindow,
    QPlainTextEdit,
    QPushButton,
    QSplitter,
    QVBoxLayout,
    QWidget,
)


class LogDrawer(QWidget):

    def __init__(self, parent=None):
        super().__init__(parent)
        layout = QVBoxLayout(self)
        layout.setContentsMargins(4, 4, 4, 4)
        layout.setSpacing(4)

        # Header-Leiste
        header = QHBoxLayout()
        header.addWidget(QLabel("<b>System-Log</b>"))
        header.addStretch()

        btn_copy = QPushButton("In Zwischenablage")
        btn_copy.clicked.connect(self.copy_to_clipboard)
        header.addWidget(btn_copy)

        btn_close = QPushButton("✕")
        btn_close.setFixedWidth(28)
        btn_close.clicked.connect(self.hide)
        header.addWidget(btn_close)

        # Monospace Textbereich
        self.text_edit = QPlainTextEdit()
        self.text_edit.setReadOnly(True)
        self.text_edit.setStyleSheet(
            "font-family: monospace; font-size: 11px; background-color: #1e1e1e; color: #abb2bf;"
        )

        layout.addLayout(header)
        layout.addWidget(self.text_edit)

    def append_log(self, full_traceback: str):
        self.text_edit.appendPlainText(full_traceback + "\n" + ("-" * 60))

    def copy_to_clipboard(self):
        QApplication.clipboard().setText(self.text_edit.toPlainText())


class MainWindow(QMainWindow):

    def __init__(self):
        super().__init__()

        # Vertikaler Splitter für Canvas + Drawer
        self.splitter = QSplitter(Qt.Vertical)
        self.canvas = QWidget()  # Stellvertreter für DocumentCanvas
        self.log_drawer = LogDrawer()
        self.log_drawer.hide()

        self.splitter.addWidget(self.canvas)
        self.splitter.addWidget(self.log_drawer)
        self.setCentralWidget(self.splitter)

        # Statusleiste initialisieren
        self.status_error = ErrorStatusWidget(
            on_click_callback=self.toggle_log_drawer
        )
        self.statusBar().addWidget(self.status_error)

        # Globalen Event-Bus verbinden
        error_bridge.error_occurred.connect(self.handle_system_error)

    def handle_system_error(self, short_msg: str, full_tb: str):
        self.status_error.show_error(short_msg)
        self.log_drawer.append_log(full_tb)

    def toggle_log_drawer(self):
        if self.log_drawer.isVisible():
            self.log_drawer.hide()
        else:
            self.log_drawer.show()
            # Splitter-Größen: z.B. 75% Canvas, 25% Log
            h = self.height()
            self.splitter.setSizes([int(h * 0.75), int(h * 0.25)])

```

## 4. Konsequenzen

### Positiv

* **Ununterbrochener Workflow:** Keine Blockade durch modale Bestätigungsdialoge.
* **Präzise Kontextualisierung:** Programmierfehler bleiben am Code in der Zelle verortet; Systemfehler bleiben der Anwendungsüberwachung vorbehalten.
* **Diagnosefähigkeit im Release-Betrieb:** Auch im Standalone-AppImage oder unter Windows ohne Konsole sind Systemfehler und Absturzgründe über das Log sofort lesbar und kopierbar.
* **Geringe UI-Komplexität:** Solange keine Fehler auftreten, bleibt das Interface absolut sauber und unaufdringlich (`hide()`).

### Negativ / Mehraufwand

* **Splitter-Zustandsverwaltung:** Das Ein- und Ausblenden des Drawers erfordert die saubere Wiederherstellung der Größenverhältnisse (`setSizes`) im `QSplitter`.
* **Speicherbegrenzung:** Der Log-Puffer im `QPlainTextEdit` sollte bei langlebigen Sitzungen auf eine maximale Blockanzahl (z. B. `setMaximumBlockCount(1000)`) begrenzt werden.
