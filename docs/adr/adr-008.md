# ADR 0008: Native Qt-Widgets für Quarto-Blocksemantik (Figures & Callouts)

## Status

Akzeptiert

## Kontext

Rosida nutzt `QTextBrowser` / `QTextDocument` für die Darstellung formatierter Textzellen. Qt unterstützt jedoch nur eine stark eingeschränkte Untermenge von HTML4/CSS2.1:

* **Bilder:** Keine automatische Skalierung, kein zentriertes Layout ohne CSS-Klimmzüge, keine Web-Unterstützung ohne manuelle `loadResource()`-Eingriffe und fehlende semantische Verknüpfung mit Quarto-Abbildungsbezeichnern (`#fig-...`).
* **Strukturblöcke:** Quarto Callout-Boxen (`::: {.callout-note}`) erfordern komplexe HTML-Verschachtelungen (`<div>`, Rahmen, Inline-SVG/Bilder für Icons), die in der Qt-Rich-Text-Engine fehleranfällig und visuell inkonsistent gerendert werden.
* **Format-Fidelity:** Das Parsen und Rückübersetzen von HTML in Markdown beim Speichern birgt das Risiko von Formatverlusten.

## Entscheidung

Rosida verzichtet darauf, alle Dokumentblöcke zwingend in ein einziges `QTextBrowser`-HTML-Dokument zu zwingen. Stattdessen:

1. **Quarto als nativer Speicherstandard:** Der Quelltext in der Zelle bleibt unverändertes, valides Quarto (`.qmd`) bzw. CommonMark.
2. **Spezialisierte View-Widgets:** Erkennt `InPlaceCell` beim Rendern spezifische Quarto-Blockkonstrukte, instanziiert sie dedizierte PySide6-Widgets:
* `FigureWidget` für Bildblöcke mit Labels und Bildunterschriften.
* `CalloutWidget` für Hinweis-, Warn- und Tipp-Boxen mit nativen `qtawesome`-Vektor-Icons.
* `MathTextBrowser` weiterhin ausschließlich für Fließtext, Formeln und Listen.


3. **Lossless Export:** Beim QMD-Export (`export_qmd`) und Markdown-Speichern werden die Zelleninhalte 1:1 als Passthrough übernommen, ohne dass ein Konverter den Text verändern muss.

## Konsequenzen

### Positiv

* **Visuelle Qualität:** Scharfe Icons, saubere Rahmen und konsistente Abstände über native Qt-Layouts statt brüchiger CSS-Hacks.
* **Entkopplung:** Bildlade-Logik (Caching, HTTP-Fetch, DPI-Skalierung) ist vollständig im `FigureWidget` isoliert.
* **Tool-Kompatibilität:** Vollständige Kompatibilität zum Quarto-CLI-Ökosystem ohne Vendor-Lock-in.

### Negativ / Trade-offs

* Zellen mit gemischten Inhalten (z. B. drei Absätze Text, unterbrochen von einer Callout-Box) müssen entweder als separate Zellen geführt oder vom Renderer in Sub-Widgets zerlegt werden.
